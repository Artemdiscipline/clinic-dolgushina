# Сайт Клиники Дарьи Долгушиной

Локальный многостраничный сайт на TypeScript, React и Vinext/Next.js.

## Запуск

~~~bash
npm install
npm run dev
~~~

Production-проверка:

~~~bash
npx tsc --noEmit
npm run lint
npm run build
~~~

## Где обновлять контент

Основной контент, ссылки, услуги, специалисты, рейтинги и юридические сведения
находятся в data/site.ts. Перед публикацией укажите подтверждённый домен в
NEXT_PUBLIC_SITE_URL по примеру .env.example.

## Что нужно получить от клиники

- фирменные фотографии интерьера и команды с подтверждёнными правами;
- полные имена специалистов, образование, действующую аккредитацию, стаж и
  направления работы;
- актуальный прайс и точную длительность каждой услуги;
- проверенные значения рейтингов и количество отзывов с датой проверки;
- документы о медицинской лицензии и перечне разрешённых работ, если планируется
  публикация медицинских услуг;
- материалы «до/после» и подтверждения согласия клиентов на публикацию.

## Включение медицинских услуг

По умолчанию medicalServicesEnabled: false, поэтому медицинские услуги не
попадают в каталог, навигацию, маршруты или SEO-разметку. Порядок безопасного
включения описан комментарием над medicalConfig в data/site.ts: сначала
нужно заполнить держателя и номер лицензии, ссылку на реестр, разрешённые работы
и подтверждённых специалистов, затем добавить проверенные услуги и только после
этого переключить флаг.

Сайт не содержит формы, теряющей данные: запись ведёт в Yclients, дополнительные
каналы связи — телефон, WhatsApp и Telegram.
